# A SIMPLE, BASIC, and ELEMENTARY Login Form
This login form is extremely insecure and is intended for education purposes. Do not use this in any serious setting.

___

## About
This login form was created as part of HW 3 for CSCE-477. As per the assignment's directions, it requests the user's email and password. It ensures that neither field is blank, that the email contains an @ sign, and that the password is at least 8 characters long, and it will prompt the user if any of those three requirements are not met.
